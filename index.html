ClaimsRAG, live replay

An assistant for auto claims adjusters. Pick a question and watch what happens behind the answer. This is a scripted replay of the real behavior, on synthetic claims. It does not call a server or a model.

Every document here is synthetic. The assistant advises; the adjuster decides.

Does hybrid search actually help?

34 claims questions, scored on 2026-10-21 by a local judge model. Flip between plain vector search and the full pipeline.

Faithfulness and coverage were only scored for the hybrid pipeline. Faithfulness moves a few points between runs; treat it as a range, not a single truth. Small case counts, single runs: this is a portfolio proof of concept, not a production claim.
